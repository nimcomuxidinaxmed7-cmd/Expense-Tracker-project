 About
This is a Currency Converter and Expense Tracker project. It helps users add their expenses, choose different currencies, and keep track of how much they spend.

Features
- Select a home currency.
- Add expenses with a description and amount.
- Choose a currency and category.
- View expenses and the total amount spent.
- Use an API to get exchange rates.

Technologies Used
- HTML
- CSS
- JavaScript
- Exchange Rate API

 How to Run
1. Open the project in VS Code.
2. Open index.html in your browser.
3. Select a currency and start adding expenses.
